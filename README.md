# Roast Lab — Craft Specialty Coffee Roastery

Интерактивная крафтовая кофейная платформа с 5-осевым радаром дескрипторов вкуса, 3-шаговым квизом подбора зерна и Telegram-ботом с предзаказом напитков к приходу.

## 🌟 Ключевой функционал

1. **Крафтовая эстетика:** Текстуры крафтовой бумаги, теплая палитра (овсяный крем `#F4EFEA`, терракота `#D97757`, темный эспрессо `#2B1E1A`, шалфей `#8A9A86`).
2. **Интерактивный радар вкуса (Flavor Radar):**
   - 5-осевая динамическая SVG-диаграмма: Кислотность (Acidity), Сладость (Sweetness), Горечь (Bitterness), Плотность тела (Body), Аромат / Флоральность (Floral).
   - Плавная интерполяция координат вершин многоугольника при переключении моносортов (Эфиопия, Колумбия, Кения, Бразилия, Коста-Рика, Руанда).
   - Детальные дескрипторы вкуса, метод обработки (мытая, натуральная, honey) и высота произрастания над уровнем моря.
3. **3-Шаговый Кофейный Квиз (Bean Finder):**
   - Шаг 1: Способ заваривания (Фильтр V60, Эспрессо, Френч-пресс, Колд Брю, Напитки с молоком).
   - Шаг 2: Вкусовой вектор (Яркий ягодный, Сладкий шоколадно-ореховый, Цветочный чайный, Плотный сливочный).
   - Шаг 3: Предпочтения по крепости и молоку.
   - Выдача персонализированного лота и точного рецепта экстракции (помол, температура воды, пропорция кофейного зерна к воде, время пролива).
4. **Витрина и Корзина:**
   - Моносорта в пачках 250г / 1кг.
   - Дрип-пакеты в наборах по 10 шт для быстрого заваривания без весов и воронок.
   - Оформление заказа с валидацией контактных данных.
5. **Telegram-бот (Aiogram 3.x):**
   - Категории «☕ Зерно», «💧 Дрип-пакеты», «⏳ Предзаказ к приходу».
   - Выбор времени самовывоза (через 10 мин, 15 мин, 30 мин, ко времени).
   - Проверка рабочих часов кофейни (08:00–22:00) с возможностью заказа к утреннему открытию при ночном визите.
   - Функция 1-Click Repeat Order для мгновенного повтора прошлого заказа.
   - Маршрутизация заказа бариста и уведомление владельца (@Idrisov_prod).

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения и API
```bash
python -m uvicorn backend.app:app --host 0.0.0.0 --port 3012 --reload
```
Веб-интерфейс доступен по адресу: `http://localhost:3012`

### 3. Запуск Telegram-бота
```bash
python -m bot.bot
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
